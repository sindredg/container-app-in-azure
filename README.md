# Azure Container App with Terraform

A small project that builds and deploys a containerized website to Microsoft Azure using Terraform.

## Goals

- Use standard Terraform workflow
- Manage Azure infrastructure as code
- Build and store a container image
- Deploy the image with Azure Container Apps
- Use Git and GitHub for version control

## Planned Azure resources

- Resource group
- Azure Container Registry
- Container Apps environment
- Azure Container App
- Managed identity
- Log Analytics workspace
